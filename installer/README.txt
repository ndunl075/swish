Swish: turn every file upload field into a basketball hoop.

INSTALL

  Windows:        double-click "Install Swish.cmd"
  macOS / Linux:  run  sh install.sh  in this folder

The installer copies Swish to a permanent folder and opens your browser's
extensions page. Browsers only allow one install step to be done by you:

  1. Turn on Developer mode.
  2. Click "Load unpacked".
  3. Choose the folder the installer printed (on Windows it's already on
     your clipboard, so you can paste it).

Works in Chrome, Edge, Brave and other Chromium browsers.

UPDATE

Download the new release, run the installer again, then click the reload
icon on the Swish card in your extensions page.

UNINSTALL

Click Remove on the Swish card in your extensions page, then delete the
folder the installer created.

HOW TO PLAY

Drag a file onto any page with an upload field and drop it anywhere.
Then grab the file and drag to aim. Release to shoot.
Esc puts it away without uploading.
